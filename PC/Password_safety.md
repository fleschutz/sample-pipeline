Password Safety Checklist
===============

For maximum security please follow these guidelines when using passwods:

1. **Avoid Passwords**
   If possible, use [Passkeys](https://en.wikipedia.org/wiki/WebAuthn) instead.

2. **Use Random Characters**

3. **Use Enough Characters**

4. **Do Not Reuse Passwords**

5. **Use a Password Manager**

"Good passwords mean door locked, bad passwords mean open doors."
